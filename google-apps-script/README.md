# 신청 폼 백엔드 연동 (Google Apps Script)

무료 체험 신청 폼 제출 시 (1) Google Sheet 저장, (2) 관리자 알림 메일, (3) 신청자 자동회신 메일을 처리합니다.
서버 호스팅이나 비용 없이 Google 계정만으로 동작합니다.

## 1. Google Sheet 만들기

1. [Google Sheets](https://sheets.google.com)에서 새 스프레드시트를 만듭니다. (예: "제주AI바이브코딩 신청내역")
2. 상단 메뉴에서 **확장 프로그램 → Apps Script** 클릭.

## 2. 스크립트 붙여넣기

1. 열린 Apps Script 편집기에서 기본 `Code.gs` 내용을 모두 지우고, 이 폴더의 [`Code.gs`](./Code.gs) 내용을 그대로 붙여넣습니다.
2. 상단의 `NOTIFY_EMAIL` 값이 `yswoola99@gmail.com` 인지 확인합니다. (알림을 받을 이메일을 바꾸고 싶으면 이 값만 수정)
3. 저장 (Ctrl+S / Cmd+S)합니다.

## 3. 웹 앱으로 배포

1. 우측 상단 **배포 → 새 배포** 클릭.
2. 유형에서 톱니바퀴를 눌러 **웹 앱** 선택.
3. 설정:
   - 설명: `apply-form-backend` (자유롭게)
   - 다음 사용자 권한으로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** (익명 사용자 포함)
4. **배포** 클릭 → Google 계정 권한 승인 (스프레드시트/메일 발송 권한 허용).
5. 배포 완료 후 나오는 **웹 앱 URL**을 복사합니다. (`https://script.google.com/macros/s/xxxxx/exec` 형태)

> 스크립트를 수정한 뒤에는 "새 배포"가 아니라 기존 배포에서 **배포 관리 → 편집(연필 아이콘) → 새 버전** 으로 업데이트해야 URL이 유지됩니다.

## 4. 프론트엔드에 URL 연결

`js/main.js` 상단의 다음 줄을 방금 복사한 웹 앱 URL로 교체합니다.

```js
const APPLY_ENDPOINT = 'https://script.google.com/macros/s/여기에_배포된_ID/exec';
```

## 5. 테스트

1. 사이트에서 신청 폼을 실제로 제출해봅니다.
2. Google Sheet에 새 행이 추가되는지 확인합니다.
3. `yswoola99@gmail.com` 으로 알림 메일이 오는지 확인합니다.
4. 폼에 입력한 이메일로 "접수되었습니다" 자동회신 메일이 오는지 확인합니다.

동작하지 않으면 Apps Script 편집기의 **실행** 탭에서 오류 로그를 확인하세요. 대부분 배포 시 "액세스 권한이 있는 사용자"를 **모든 사용자**로 설정하지 않았거나, 권한 승인을 완료하지 않은 경우입니다.
